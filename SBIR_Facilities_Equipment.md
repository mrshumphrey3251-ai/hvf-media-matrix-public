# Project Ebony: Phase I Facilities and Equipment

## 1. The Edge Computing Environment (Heavy Iron)
Humphrey Virtual Farm operates a localized, high-performance edge-computing server matrix. This "heavy iron" architecture provides the dedicated processing power required to run the Project Ebony zero-trust state machine and internal Python rendering engines without external API dependencies.

## 2. Sovereign Development Environment
All development, verification, and code generation occur within a strictly controlled, localized Linux subsystem. This ensures the foundational architecture remains sterile and immune to external supply-chain vulnerabilities during the Phase I research period.
