# Executive Engineering Directive - FASTEN-001
## Trailer-Chassis Reinforcement for 5-ton MIL-SPEC ECU & Crystal Group RS-Series Server Rack
**Prepared by:** E.B.O.N.Y. - Project Management Interface  
**Version:** 1.0 | **Date:** 2026-11-11 | **Status:** APPROVED (MFA Token: 515757)

### 1. Scope & Static / Dynamic Load Summary
- Total Supported Mass: 3,200 kg (ECU: 2,200 kg, Server Rack: 800 kg, Ancillary: 200 kg)
- Static Load (SL): 31.39 kN
- Dynamic Shock Load (DL, 3g rough-terrain envelope): 94.17 kN
- Design Load (FoS = 1.5): 141.26 kN (Rated for >= 141 kN per mounting station)

### 2. Structural Steel & Gusset Specifications
- Primary Plates & Gussets: ASTM A572 Grade 50 (Yield: 345 MPa, Tensile: 450 MPa), 12mm thickness
- Dual Triangular Gussets: 300mm base x 250mm height, 8mm full-penetration fillet weld (Shear capacity: ~373 kN per gusset)
- Floor Cut-Through Reinforcement Plate: ASTM A514 Grade C, 16mm thick, 600mm x 600mm square, welded perimeter

### 3. Fasteners & Pre-load
- Anchor Bolts (Deck): 4x M24 Grade 8 (ASTM A490) per station, torqued to 180 Nm (clamping force >= 70% tensile capacity)
- Frame-to-Gusset: 4x M20 Grade 8 (ASTM A325) per station, torqued to 150 Nm

### 4. Verification & NDT
- Hydraulic static proof test to 141 kN
- Ultrasonic NDT inspection across 100% of perimeter welds
