# HVF SOVEREIGN MIRROR PROTOCOL
## DIRECTIVE: LOCALIZED REAL-TIME SYNCHRONIZATION

To achieve flawless, cross-platform mobility, the matrix utilizes Syncthing to provide near real-time file mirroring between hardware nodes.

### PHASE 1: HARDWARE SETUP
1. Install Syncthing (enterprise decentralized mirroring).
2. Add your other devices as 'Trusted Nodes' via their unique Device IDs.

### PHASE 2: VAULT SYNCHRONIZATION
Share the foundational directories across all nodes: ~/HVF_MEDIA_MATRIX and ~/HVF_MEDIA_MATRIX_PUBLIC.
