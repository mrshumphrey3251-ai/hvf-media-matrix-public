# Ebony AI: Edge-Device SDKs
**Redacted Public Overview**

To eliminate integration friction for enterprise partners, drone manufacturers, and IoT sensor vendors, Humphrey Virtual Farm has released the official Ebony Edge-Device SDKs.

## Supported Architectures
* **Python SDK:** Designed for rapid prototyping, Raspberry Pi gateways, and standard ag-tech deployments.
* **C++ SDK:** Engineered for legacy industrial IoT controllers and embedded hardware requiring strict memory management.
* **Rust SDK:** The ultimate solution for high-frequency trading platforms, next-generation drone flight controllers, and data-center load monitors demanding memory-safe, ultra-low latency execution.

## Core Capabilities
* Automated authentication and JWT bearer token management.
* Standardized payload packaging for RGB optical data, dielectric moisture, and external power-grid variables.
* Built-in error-recovery and retry logic for zero-connectivity environments.

*Full binary distributions, endpoint URIs, and source repositories remain strictly confidential under HVF Executive Governance.*
