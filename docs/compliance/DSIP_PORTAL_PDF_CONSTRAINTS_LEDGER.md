# DEFENSE SBIR/STTR INNOVATION PORTAL (DSIP): PDF FORMATTING CONSTRAINTS
**Contractor Entity:** Humphrey Virtual Farms LLC  
**Commercial and Government Entity (CAGE) Code:** 1AHA8  
**Statutory Enforcement:** DoD SBIR 24.4 Broad Agency Announcement (BAA)  

---

## 1. MANDATORY DOCUMENT FORMATTING RULES
If any uploaded Volume violates these constraints, the DSIP portal will trigger an automated hard-rejection.

* **File Format:** All uploaded Volumes (2 through 6) MUST be in Portable Document Format (PDF).
* **Font Size Constraint:** No smaller than 10-point font (except for table legends/graphics, which may be 8-point). Recommended: 11-point or 12-point Arial or Times New Roman.
* **Page Margins:** Minimum 1-inch margins on all sides.
* **Page Layout:** 8.5 x 11-inch standard letter size.
* **Volume 2 Page Cap:** The Technical Proposal (Volume 2) is strictly capped at **15 pages** (or 20 pages depending on specific DoD component instructions). Any pages beyond the cap will be programmatically truncated and ignored by evaluators.

---

## 2. STRICT PDF FLATTENING & SECURITY RULES
* **No Active Content:** PDFs must NOT contain embedded macros, JavaScript, audio, video, or executable files.
* **No Encryption/Passwords:** Do not apply password protection or encryption to the PDFs. The DSIP portal must be able to read and parse the text for automated compliance checks.
* **Flattened Layers:** All layers, digital signatures (outside of Volume 1), and interactive form fields must be "flattened" into a static image/text layer prior to upload.

---

## 3. PRE-UPLOAD CONVERSION PROCEDURE
Before uploading to DSIP, execute the following conversion process for Markdown files:
1. Export the Markdown files (Volumes 2-6) to Microsoft Word or Google Docs to apply strict 1-inch margins and pagination.
2. Verify font scaling (minimum 10-point).
3. Select **"Print to PDF"** (rather than "Save As PDF") to guarantee all active layers are flattened and stripped of hidden metadata.
4. Verify file sizes do not exceed the portal maximum (typically 10 MB per volume).
