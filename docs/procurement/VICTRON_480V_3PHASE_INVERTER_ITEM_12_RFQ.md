# HVF Procurement: Victron 480V 3-Phase Inverter Stack (Item 12) RFQ
**Issuing Entity:** Humphrey Virtual Farms LLC (CAGE: 1AHA8 | UEI: S1M4ENLHTDH5)  
**Budget Allocation:** $38,500.00 (CapEx, Contractor-Acquired Property)  
**Target Vendors:** Victron Energy / Schneider Electric / SMA America  

## Technical Requirements
- **Topology:** True 3-Phase (480V L-L / 277V L-N, 60 Hz) pure sine wave bidirectional inverter/charger stack.
- **Continuous Output:** 150 kVA continuous nominal output @ 40°C ambient.
- **Surge / Motor-Start Capacity:** >= 300 kVA peak surge capacity (minimum 10-second duration) to start twin-shaft concrete mixer motors.
- **DC Bus Coupling:** High-efficiency interface with 350V–750V DC nominal bus (500 kWh LFP battery bank).
- **Control & Telemetry:** Native Modbus RTU / Modbus TCP registers for real-time per-phase voltage, current, frequency, active/reactive power, and fault codes.
- **Switchover & Islanding:** Seamless grid-to-island transfer time <= 20ms; black-start capability from unpowered battery bank.
- **Environmental:** Conformal coated PCBs; shock/vibration mounting provisions for 53-ft drop-deck tactical trailer integration.
