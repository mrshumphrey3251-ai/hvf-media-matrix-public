# HVF Procurement: Wolfspeed 1200V SiC MOSFETs & Gate Drivers (Item 11) RFQ
**Issuing Entity:** Humphrey Virtual Farms LLC (CAGE: 1AHA8 | UEI: S1M4ENLHTDH5)  
**Budget Allocation:** $14,200.00 (CapEx, Contractor-Acquired Property)  
**Target Vendors:** Wolfspeed (Cree Power) / onsemi / STMicroelectronics  

## Technical Requirements
- **Silicon Substrate:** 1200V N-Channel Silicon Carbide (SiC) Power MOSFETs (bare die or discrete TO-247-4 / XM3 module form factor).
- **Current Rating:** Continuous drain current >= 100A per device @ 25°C; pulsed drain current >= 250A.
- **Switching Speed:** Rise/fall time <= 20ns; compatible with modeled 36.75ns total interlock gate cutoff velocity.
- **On-State Resistance ($R_{DS(on)}$):** Ultra-low on-resistance <= 15 mΩ to minimize thermal dissipation on 480V/750V DC bus.
- **Gate Driver Compatibility:** Differential optical/isolated high-side gate drivers (CMRR >= 100 kV/μs, propagation delay <= 30ns).
- **Qualification:** AEC-Q101 qualified or MIL-STD-750 test method compliant; continuous operational junction temperature up to 175°C.
- **Package Deliverables:** 24 engineering sample units + 4 evaluation driver test boards for bench HIL oscilloscope verification.
